# دروازه ها باز است

Vite + React UI for the Iran SIM SMS gateway. Persian is the default language (RTL); English is available from the language switch.

Safavid-inspired lapis / turquoise / emerald tile theme.

```bash
npm install
npm run dev
```

Runs on http://127.0.0.1:43123

- Local API: set `VITE_API_BASE` or run without it against `http://127.0.0.1:5088` in DEV.
- Published app: set `FIELDSENSE_API_BASE` / `config.js`; otherwise sample mode (OTP `000000`).
